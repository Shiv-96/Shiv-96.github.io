# Shiv Kumar - Portfolio (React + Vite)

## Run locally
    npm install
    npm run dev

## Before you deploy
Copy your existing `Pictures/` and `Resume/` folders into `public/` (keep the same file names). Content lives in `src/data.js`.

## Deploy to GitHub Pages (repo: shiv-96.github.io)
    npm run deploy
This builds and publishes `dist/` to the `gh-pages` branch. In GitHub: Settings > Pages > set the source to that branch.
Keep your old site's files out of the way, or replace them with this project's source on `main`.

## Update content
- Experience, skills, projects, contact details: `src/data.js`
- Colors and fonts: variables at the top of `src/styles.css`
